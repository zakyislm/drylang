# Scope & Closures

DryLang uses lexical scoping. Functions can "capture" variables from their surrounding environment.
```rust
multiplier = 10

fn makeAdder(x) {
    rev fn(y) => {
        // 'multiplier' and 'x' are captured from the outer scope!
        rev (x + y) * multiplier 
    }
}

addFive = makeAdder(5)
pt(addFive(2)) // (5 + 2) * 10 = 70
```
