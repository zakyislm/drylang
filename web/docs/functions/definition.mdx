# Function Definition

Define a function using the `n` keyword.
```rust
fn greet(name) {
    pt("Hello, " + name + "!")
}

greet("Zaky")
```
## Returning Values
Use the eturn\ keyword to output a value from a function.
```rust
fn add(a, b) {
    rev a + b
}

result = add(10, 20)
pt("Result:", result) // 30
```
