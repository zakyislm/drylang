# Database

DryLang has **SQLite natively compiled into the runtime**. You do not need to install any external drivers.

## \db(action, ...args)
### 1. Connect
Always connect first.
```rust
db("connect", "sqlite", "app.db")
```
### 2. Execute (Insert / Update / Delete)
Executes a query without expecting a return row.
```rust
db("exec", "CREATE TABLE users (id INTEGER PRIMARY KEY, name TEXT)")
db("exec", "INSERT INTO users (name) VALUES ('Zaky')")
```
### 3. Query (Select)
Returns an array of maps (rows).
```rust
let users = db("query", "SELECT * FROM users")
pt(users[0].name)
```
### 4. Close
```rust
db("close")
```
