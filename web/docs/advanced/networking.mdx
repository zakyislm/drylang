# Networking

## HTTP Requests with eq()Make instant HTTP calls.
```rust
// GET request
res = req("https://jsonplaceholder.typicode.com/todos/1")
pt(res)

// POST request with body
res2 = req("https://api.example.com", "POST", "{"name": "Zaky"}")
```
## JSON Parsing with \json()Convert JSON strings into DryLang Maps/Arrays.
```rust
raw = "{"status": 200, "message": "ok"}"
data = json(raw)
pt(data.message) // "ok"
```
