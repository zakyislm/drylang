# Networking

## HTTP Requests with eq()Make instant HTTP calls.
```rust
// GET request
let res = req("https://jsonplaceholder.typicode.com/todos/1")
pt(res)

// POST request with body
let res2 = req("https://api.example.com", "POST", "{"name": "Zaky"}")
```
## JSON Parsing with \json()Convert JSON strings into DryLang Maps/Arrays.
```rust
let raw = "{"status": 200, "message": "ok"}"
let data = json(raw)
pt(data.message) // "ok"
```
