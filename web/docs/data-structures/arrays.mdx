# Arrays

Arrays hold an ordered list of values. They are dynamically sized and can hold mixed types.
```rust
let fruits = ["Apple", "Banana", "Cherry"]
pt(fruits[0]) // Apple

// Reassigning an index
fruits[1] = "Mango"
pt(fruits)
```
Check out the [Collections Built-ins](/docs/built-ins/collections) for methods to modify arrays like `push()`, `pop()`, and `len()`.
