# Maps

Maps (or dictionaries/objects) hold key-value pairs.
```rust
let user = {
    name: "Zaky",
    age: 25,
    role: "admin"
}

// Access via dot notation or brackets
pt(user.name)
pt(user["age"])

// Assignment
user.location = "Jakarta"
```
Check out the [Collections Built-ins](/docs/built-ins/collections) for methods to inspect maps like `key()`, `al()`, and `has()`.
