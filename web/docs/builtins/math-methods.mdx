# Math Methods

Math functions are accessible either globally or via the `math.` namespace.

## Absolute (`abs`)
```rust
abs(-5) // 5
```

## Min and Max (`min`, `max`)
```rust
min(3, 9) // 3
max(3, 9) // 9
```

## Random (`rnd`)
Generates a random integer from `0` to `n-1`.
```rust
rnd(10) // 0 to 9
```
If you pass a float, it rounds to the nearest integer.
```rust
rnd(3.7) // 4
```

## Advanced Math (`math.`)
```rust
math.sqrt(16)  // 4
math.pow(2, 10) // 1024
```
