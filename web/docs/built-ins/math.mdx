# Math Operations

## `math(operation, ...args)Advanced math toolkit. Supports: "sqrt"`, "pow"`, "ceil"`, "floor"`, "sin"`, "cos"`, "tan"`.
```rust
pt(math("sqrt", 16)) // 4
pt(math("pow", 2, 3)) // 8
```
## Quick Shorthands
- **um(val)\**: Casts string to number.
- **`bs(val)`**: Absolute value.
- **`min(a, b)`**: Minimum value.
- **`max(a, b)`**: Maximum value.
- **nd()\**: Random integer.
