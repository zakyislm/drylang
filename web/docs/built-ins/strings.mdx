# String Manipulation

## \spl(string, delimiter)Splits a string into an array.
```rust
words = spl("apple,banana,orange", ",")
// ["apple", "banana", "orange"]
```
## \	rm(string)Removes whitespace from both ends.
```rust
clean = trm("   hello   ") // "hello"
```
## `cap(string)` & \low(string)Uppercase and lowercase.
```rust
pt(cap("zaky")) // "ZAKY"
pt(low("ZAKY")) // "zaky"
```
## \mod(string, old, new)Replaces all instances of a substring.
```rust
txt = mod("hello world", "world", "drylang") // "hello drylang"
```
## `has(string, substring)Returns `	rue\ if the substring exists.
```rust
exists = has("hello", "ell") // true
```
