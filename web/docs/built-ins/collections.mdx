# Collections & Arrays

## \has(collection, target)The ultimate checker. 
- In **Strings**: Checks if substring exists.
- In **Maps**: Checks if key exists.
- In **Arrays**: Checks if value exists.
```rust
let data = { token: "123" }
pt(has(data, "token")) // true
```
## \len(collection)Returns the length of a string, array, or map.

## Array Specifics
- **`pop(array)`**: Removes and returns the last element.
- **m(array, index)\**: Removes an element at a specific index.
- **`sort(array)`**: Sorts the array.

## Map Specifics
- **`key(map)`**: Returns an array of all keys.
- **`al(map)`**: Returns an array of all values.
