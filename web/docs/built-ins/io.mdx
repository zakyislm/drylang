# Input & Output

## \pt(...args)Print data to the terminal. Accepts infinite arguments and automatically spaces them.
```rust
pt("Welcome to", "DryLang!", 2026) 
// Output: Welcome to DryLang! 2026
```
## \in(prompt)Accept user input from the terminal. Optionally takes a string prompt to display first.
```rust
let name = in("What is your name? ")
pt("Hello,", name)
```
