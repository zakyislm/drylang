# Loops

DryLang uses the `lp` keyword for all looping.

## Fixed Count Loop
Loop a specific number of times. The index variable `i` (starting at 0) is automatically injected into the loop context!
```rust
lp 5 {
    pt("hello " + str(i)) // i = 0, 1, 2, 3, 4
}
```

## Conditional Loop
Loop while a condition is true:
```rust
count = 0
lp count < 3 {
    pt(count)
    count = count + 1
}
```

## Infinite Loop
Omit the expression for an infinite loop:
```rust
lp {
    pt("forever")
}
```

## Done and Con
Use `done` to break out of a loop, and `con` to skip to the next iteration.
```rust
lp 10 {
    if i = 5 {
        done
    }
    pt(i)
}
```

## Parallel Execution (mul)
If you want to execute multiple iterations asynchronously in parallel, use the `mul` keyword. Like `lp`, `mul` also automatically injects the `i` index into its context:
```rust
// Spawns 10 parallel background jobs, each receiving its own `i` (0 to 9)
mul 10 processJob(i)
```
