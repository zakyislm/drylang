# Conditionals

## If / Elif / El
DryLang uses `if`, `elif`, and `el` (else).
```rust
score = 85

if score > 80 {
    pt("Great job!")
} elif score > 50 {
    pt("Not bad")
} el {
    pt("Keep trying!")
}
```

> **Note:** DryLang does **not** have a ternary conditional operator (`? :`). Syntax minimalism dictates that `if/el` or the null coalescing operator (`??`) is sufficient.

Additionally, the `unknown` keyword resolves to falsy:
```rust
data = unknown
if (data) {
    // skipped
} el {
    pt("Falsy!")
}
```

## On (Switch)
The `on` statement replaces traditional `switch`. No `case` keyword — just value and block.
```rust
role = "admin"

on(role) {
    "admin" {
        pt("Access granted: Admin")
    }
    "user" {
        pt("Access granted: User")
    }
}
```
