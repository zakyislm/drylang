# Variables

In DryLang, you can declare a variable simply by assigning a value to it, or you can explicitly use the `let` keyword.

## Declaration and Assignment
```rust
// Implicit declaration
name = "Zaky"
age = 25

// Explicit declaration
city = "Jakarta"
```
Variables are dynamically typed, meaning you can reassign them to a different type later:
```rust
score = 100
score = "One hundred" // Perfectly valid
```
