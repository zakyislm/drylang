# Installation

Currently, DryLang is compiled from source via Go. 

## Prerequisites
- Go 1.20 or newer installed on your machine.

## Steps

1. Clone the repository:
```bash
git clone https://github.com/drylang/drylang.git
cd drylang
```

2. Build the executable:
```bash
go build -o dry.exe .
```
*(Note: For Linux/macOS, use `go build -o dry .`)*

3. Add the binary to your system PATH to use the `dry` command anywhere.
